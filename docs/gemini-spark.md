# Gemini Spark 조간 연결

Spark 조간 연결을 검증 중입니다. 기존 조간 API 예약은 실제 Spark 제출을 검증할 때까지 유지합니다.

- `/spark.html`에서 기존 보고 연결 키로 누적 기사 최대 120건·60,000자와 전일 이슈를 읽습니다. 원문 전체나 새 웹 검색은 사용하지 않습니다.
- 날짜·24시간 기사 시각·제외 키워드·기존 무관 판정·근거 ID·해외 최대 2개·이슈 최대 5개를 검증합니다.
- 접수 결과는 기존 설정 행의 `spark_morning` 하나에 보관합니다. 같은 날짜는 덮어쓰지 않고 전체 설정 64KB 한도를 유지합니다. 새 DB 스키마 없음.
- 검증만 실행 옵션은 DB 저장과 발송을 하지 않습니다. 접수 성공은 Telegram 전달 완료가 아닙니다.
- `scripts.spark_morning`은 접수 결과를 재검증해 기존 조간 초안으로 변환합니다. LLM API를 호출하지 않습니다. 발송은 기존 `scripts.dispatch --skip-sent` 경로를 사용합니다.
- Spark는 클라우드에서 실행하지만 원격 브라우저 접근·양식 제출 승인이 필요할 수 있습니다. 승인 필요 상태에서는 무인 전달이 완료되었다고 판단하지 않습니다.
- 기존 보고 연결 키는 공개 문서나 로그에 저장하지 않습니다.
