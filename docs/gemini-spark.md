# Gemini API 전환

2026-09-21 변경: Gemini 웹 Spark 예약 보고 대신 새 기사 API 선별과 조간 분석을 사용합니다. 교대 API 키를 지원하며, 무료 등급 프로젝트만 연결합니다. 자세한 설정은 [README](../README.md#무료-ai-api와-예비-키)를 참고하세요.

`spark.html`과 `/api/spark`의 새 보고 접수는 종료했습니다. POST 요청은 인증 후 410을 반환하고 DB에 저장하지 않습니다. 수집 Actions에서 `scripts.spark_relay`를 실행하지 않으므로 이전 큐가 있어도 자동 전송하지 않습니다. 기존 웹 예약은 일시중지합니다. 이전 큐·해시는 별도 삭제하지 않습니다.

아침 분석에는 원격 브라우저나 사용자 양식 제출 승인이 필요하지 않습니다. API 키·무료 할당량·통합 수집 상태가 정상이어야 합니다. 분석 실패는 Actions 실패로 표시하며 유료 서비스로 자동 전환하지 않습니다.
